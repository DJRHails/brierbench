# BrierBench

OpenReward environment for evaluating LLM forecasting accuracy.

## Architecture

```
server.py          # Environment: tools, sessions, scoring
scoring.py         # Time-weighted Brier score
prepare_tasks.py   # Generate train/test from ForecastBench data
Dockerfile         # Environment server image (deployed via OpenReward)
sandbox.Dockerfile # Sandbox image (djrhails/brierbench-sandbox:latest)
examples/
  _common.py           # Shared: clients, agent loop, upload helpers
  zero_shot.py         # No search, immediate predict + advance
  zero_shot_research.py # Search + advance + update loop
  forecast_skill.py    # Structured methodology with distribution scripts
  batch_eval.py        # Concurrent evaluation runner
  plot_results.py      # Brier score by question date (graph-design)
  summarise_results.py # Raw Brier breakdown by source/cutoff
  brier_index.py       # Difficulty-adjusted BI using ForecastBench FEs
```

## Deployment

- **Environment**: deployed on OpenReward as `DJRHails/brierbench`
- **Server image**: auto-built from `Dockerfile` on push to `main`
- **Sandbox image**: `djrhails/brierbench-sandbox:latest` on Docker Hub (amd64)
  - Built on bonbon (x86_64): `docker build -f sandbox.Dockerfile -t djrhails/brierbench-sandbox:latest . && docker push`
  - Contains python3, uv, numpy, pandas, scipy, scikit-learn, matplotlib, sympy, statsmodels
- **Task data**: `train.json` and `test.json` uploaded to Files tab on OpenReward dashboard
  - Generated by: `uv run prepare_tasks.py --output-dir data/`
  - Mounted at `/orwd_data/` in the environment

## Running evaluations

### Environment variables

```bash
OPENREWARD_API_KEY=or_...     # OpenReward API (rollouts + sandbox)
OPENROUTER_API_KEY=sk-or-...  # LLM calls via OpenRouter
EXA_API_KEY=...               # Web search via Exa
MODEL_NAME=google/gemini-3-flash-preview  # Override model
BRIERBENCH_ENV=DJRHails/brierbench        # Override environment name
BRIERBENCH_URL=http://localhost:8081      # For local server testing
```

### Local server

```bash
BRIERBENCH_DATA_DIR=/tmp/brierbench-data python server.py
```

Server runs on port 8080. Set `BRIERBENCH_URL=http://localhost:8081` in examples to use a custom port.

### Single task

```bash
cd examples && uv run python zero_shot.py
```

### Batch evaluation

```bash
cd examples && uv run python batch_eval.py \
    --strategy zero_shot \
    --n-samples 100 \
    --concurrency 20 \
    --output /tmp/results.json
```

Strategies: `zero_shot`, `zero_shot_research`, `forecast_skill`

### Scoring

```bash
# Raw Brier breakdown
uv run python summarise_results.py /tmp/results.json

# Difficulty-adjusted Brier Index (needs ForecastBench data)
uv run python brier_index.py \
    --fixed-effects /tmp/forecastbench-data/question_fixed_effects.json \
    --forecast-dir /tmp/forecastbench-data/forecastbench-processed-forecast-sets \
    /tmp/results.json
```

## Secrets (passed to sessions)

```python
secrets = {
    "EXA_API_KEY": (exa_key, ["api.exa.ai"]),
    "OPENROUTER_API_KEY": (openrouter_key, ["openrouter.ai"]),
}
```

`EXA_API_KEY` is not a well-known OpenReward secret; must be passed as a tuple with allowed domains. `OPENROUTER_API_KEY` powers the LLM date-filter grader inside `web_search`.

## Scoring methodology

- **Reward** = `1 - time_weighted_brier` (ORS requires higher = better)
- **Time weighting**: `weight = t/T` where t = days elapsed, T = horizon
- **Brier Index**: difficulty-adjusted using ForecastBench question fixed effects
  - Formula: `BI = (1 - mean(brier - γ_j + rescale_offset)) * 100`
  - Rescale ensures a naive 0.5 forecaster scores exactly 75.0
  - Download FEs from `forecastbench.org/assets/data/question-fixed-effects/`

## Key files outside this repo
